Section 02

Color System

The palette is intentionally near-monochrome. Dark sections use #0d0d0b (warm near-black). Light sections use #f5f2ec (warm cream — NOT pure white). This warm undertone is the key differentiator from cold tech palettes.

Section 06

Layout Patterns

Home page section flow

Pattern: Dark → Light alternation

Hero = dark. Feature cards = light cream. Quote = dark. Split = light. Footer = dark. Never two consecutive dark-bg sections.

Pattern: Eyebrow → Headline → Body → CTA

Every content section opens with an all-caps eyebrow label. This is the primary navigational wayfinding layer across the whole site.

  video.currentTime = p * video.duration;
});

  family=Cormorant+Garamond:ital,wght@0,300;0,400;1,300;1,400
  &family=DM+Sans:wght@300;400;500
  &display=swap" rel="stylesheet">

Scroll reveal (Intersection Observer)

const io = new IntersectionObserver((entries) => {
  entries.forEach((e, i) => {
    if (e.isIntersecting) {
      e.target.style.transitionDelay = `${i * 80}ms`;
      e.target.classList.add('visible');
    }
  });
}, { threshold: 0.15 });

document.querySelectorAll('[data-reveal]').forEach(el => {
  el.classList.add('pre-reveal');
  io.observe(el);
});

Sticky nav transparency

const nav = document.querySelector('.iso-nav');
window.addEventListener('scroll', () => {
  nav.classList.toggle('scrolled', window.scrollY > 60);
});

Key aesthetic rules — don't break these

  • ✦ Background is #f5f2ec (warm cream), never pure white on light sections
  • ✦ Headlines are always Cormorant Garamond, never the sans-serif
  • ✦ Font weights: 300 body, 400 headlines, 500 labels — never 600+
  • ✦ Eyebrow labels precede every content section — this is structural, not decorative
  • ✦ CTAs are always lowercase (e.g. "work with us", not "Work With Us")
  • ✦ Section padding is generous: min 80px top/bottom, scales to 160px on desktop
  • ✦ Border radius on sections: 16px. Buttons: 999px (pill)
  • ✦ No drop shadows except on button hover (subtle, dark, not colorful)
  • ✦ Alternate dark/light section backgrounds — never two darks in a row
  • ✦ Teal (#1a5c52) is for links and CTA text only. Never backgrounds.
